Politique de confidentialité de Pli Scellé

Dernière mise à jour : 26 novembre 2026

Éditeur : Aït Sidi Ahmed Abdelmalek
Contact : sarl.bc@sfr.fr

Pli Scellé est une messagerie privée entre deux personnes. Cette page explique quelles données sont traitées, où elles se trouvent et comment les supprimer.

1. Ce que Pli Scellé ne demande pas

Pli Scellé ne demande ni nom réel, ni numéro de téléphone, ni adresse e-mail, ni compte. Pour créer une identité, vous choisissez un pseudonyme et un code secret.

2. Les données et où elles se trouvent

Sur votre appareil (ces données ne sont pas envoyées à l'éditeur) :

  • votre pseudonyme et les clés de votre identité, dont la clé privée est chiffrée par votre code secret ;
  • vos contacts : le nom que vous leur donnez et leur clé publique ;
  • les personnes retirées de votre liste : leur nom et leur clé publique, pour permettre une reprise avec votre sauvegarde (effacés avec votre identité) ;
  • les messages, photos, documents et messages vocaux reçus et envoyés ;
  • vos réglages.

Sur le relais (serveur Supabase, qui transmet les messages) :

  • les identifiants techniques des boîtes de messages, dérivés des clés publiques ;
  • les pseudonymes figurant dans les invitations, ainsi que les dates et la taille approximative des envois ;
  • les messages et les morceaux de fichiers, chiffrés ;
  • pour les notifications, l'adresse technique de votre appareil, si vous les activez.

Ce que le relais ne voit jamais : le contenu des messages, des photos et des documents, le nom des fichiers, le nom que vous donnez à vos contacts.

3. Le chiffrement

Les messages, photos, documents et messages vocaux sont chiffrés sur l'appareil de l'expéditeur, avec une clé partagée entre les deux personnes. Le relais ne peut pas les lire.

4. Durée de conservation

  • Les messages sont supprimés du relais une fois reçus.
  • Les morceaux de fichiers qui n'ont pas été récupérés sont supprimés au bout de 48 heures.
  • Sur votre appareil, un message à lecture unique disparaît après sa lecture. Les autres restent jusqu'à ce que vous les supprimiez.

5. Notifications

Lorsque vous les activez, les notifications ne contiennent ni texte ni nom. Elles indiquent seulement qu'une activité vous attend.

6. Vos droits

Dans « Mon identité », vous pouvez à tout moment supprimer votre identité et les données de votre appareil. Vous pouvez aussi couper le lien avec un contact : la personne sort de votre liste, mais son nom et sa clé publique restent sur l'appareil, pour une reprise avec votre sauvegarde, jusqu'à la suppression de votre identité. Pour toute demande concernant les données conservées sur le relais, écrivez à sarl.bc@sfr.fr.

7. Services utilisés

  • Relais des messages : Supabase.
  • Site de l'application web : GitHub Pages.
  • Application iPhone : téléchargée depuis l'App Store, ou installée depuis Safari, sur l'écran d'accueil.

Pli Scellé n'affiche aucune publicité et n'utilise aucun outil de mesure d'audience.

8. Modifications

Cette politique peut évoluer. La date de dernière mise à jour figure en haut de cette page.
